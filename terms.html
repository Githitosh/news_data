News Shorts・リプライニュース 利用規約

制定日：2026年11月20日

この利用規約（以下「本規約」）は、News Shorts（ニュース：https://githitosh.github.io/news_data/）とリプライニュース（https://githitosh.github.io/news_data/humor/）（あわせて以下「本サービス」）の利用条件を定めるものです。本サービスは、運営者（GitHub：Githitosh、以下「運営者」）が提供しています。本サービスを利用した時点で、本規約に同意したものとみなします。

考え方

このサービスは、リプライを見て楽しみ、軽い気持ちでニュースを見られる場所です。広告や宣伝に考えを動かされる心配がないよう、広告・宣伝・案件・PR・購入や応募の呼びかけは載せません。誹謗中傷をする場所ではありません。人を傷つける言葉、悪く言う言葉、政治家・政党・政府・メディアへの攻撃、残酷なニュース、個人の名誉や私生活に関わること、お酒・タバコは載せません。迷ったものは載せません（githito.xapi の PRINCIPLES.md）。

1. 利用できる方

  • 本規約に同意し、適用される法令のもとで本サービスを利用できる方が利用できます。
  • 会社などの団体のために利用する場合、その団体に代わって本規約に同意する権限があるものとします。

2. プライバシー

  • 本サービスに会員登録はありません。運営者は、利用者の個人情報を集めたり保存したりしません。アクセス解析や広告の仕組みも使っていません。
  • 動画にする内容は、運営者のGitHub（https://github.com/Githitosh/githito.xapi）に置いたファイルから読み込みます。本サービスのページが X（旧Twitter）に直接つながることはありません。
  • ページがつなぐ外部のサービスは次のとおりです。その際、IPアドレスなどの通信情報が各サービスに送られ、各サービスの規約とプライバシーポリシーに従って扱われます。
    • GitHub（ページとデータの配信）、Google Fonts（文字の読み込み）。これ以外にはつなぎません（翻訳サービスや、ページ自身による検索は使いません。英語のニュースは、英語のニュースアカウントの投稿から作ります）。
    • アカウントを「追加」したとき（ニュース・リプライニュースの動画の下の入力欄）：追加したXのアカウント名は、収集の依頼として運営者のプログラム（githito.xapi）に追加されます。そのために GitHub の画面が開き、利用者が自分の GitHub アカウントで送信します。依頼は GitHub 上で公開され（送信した方の GitHub アカウント名と、追加したアカウント名の一覧が誰でも見られます）、受け付けられたアカウントの投稿と、それに付いた返信を githito.xapi が集めます。アカウントを外したときも、同じ方法で一覧を送り直します。
  • 読み込んだデータ、見た動画の記録（同じものを繰り返さないため）、設定、追加した言葉は、利用者のブラウザの中に保存されます。運営者には送られません。

3. 表示される内容

  • ニュース：報道機関などがXに投稿したニュースの見出しを、投稿元の名前とリンクを付けて表示します。英語の見出しは機械翻訳で、正確でないことがあります。
  • リプライニュース：Xの個人の投稿と、それに付いた返信を2つ1組で表示します（挨拶や好意を伝えるやりとり）。それぞれの投稿者の名前（@）と元の投稿へのリンクを表示します。
  • どちらも、運営者のプログラム（githito.xapi）が30分ごとに自動で集め、3日たったものは消します。Xの投稿は、FxTwitter・vxTwitter・FixupX・X公式の埋め込みサービスを通して読みます。
  • リプライニュースでは、良いやりとりになった返信を書いたアカウントの名前を、次の収集で先に読むために記録します（アカウント名・記録した回数・点数のみ。投稿の本文は含みません）。この記録は公開せず、運営者だけが見られる非公開の場所に保存します。30日のあいだ新しく記録されなかったものは消し、全体で最大300件です。記録から外してほしい場合は、下記のお問い合わせ先までお知らせください。
  • 暴力、性的な内容、重い話題、けんか腰の言葉、広告、学校に関する言葉があるもの、プロフィールから未成年と分かる方の投稿は選ばないようにしています。ただし自動の選別のため完全ではなく、不適切なものが表示されることがあります。
  • 追加されたアカウントの投稿と返信も、ほかと同じ基準で選びます（下の「表示しません」に当たるものは載せません）。報道機関でないアカウントは、政治や特定の集団に触れる投稿なども載せず、1つのアカウントが多くを占めないように件数を限ります。短い時間に多くの依頼が届いた場合は、その送信元からの受け付けを一時的に止めます。
  • 次のものは、設定にかかわらず表示しません：残酷なニュース（殺害、遺体、拷問、性暴力、虐待、自殺、子どもが被害にあった事件など）、個人の名誉や私生活にかかわるニュース（逮捕・容疑者・起訴・判決、疑惑・告発・暴露、不倫・熱愛、炎上など）、投稿や返信の中の誹謗中傷（悪口・侮辱・差別的な言葉、脅し、人を犯罪者などと決めつける言葉、住所・本名・勤務先などを指す言葉）。言葉による自動の判定のため、完全ではありません。
  • ご自身の投稿を表示しないでほしい場合や、権利の侵害を見つけた場合は、下記のお問い合わせ先までお知らせください。確認のうえ対応します。
  • 表示される投稿・返信・見出しの権利は、それぞれの投稿者にあります。運営者が内容を書いたり、書き換えたりすることはありません（一部を抜き出しての表示と、機械翻訳の併記を除きます）。運営者は、X社および各報道機関とは関係ありません。
  • 背景の写真は、パブリックドメインなど自由に使える素材、または運営者が用意した素材を使い、出典を画面に表示しています。
